Employee Burnout & Attrition Risk Analysis

1. Overview

This project predicts employee attrition using burnout indicators and estimates financial impact using data analytics.

2. Tech Stack

Python (Pandas, Scikit-learn)

PostgreSQL

Power BI


3. Key Features

Burnout Score (0–100)

Attrition Probability (ML Model)

Revenue at Risk calculation

Risk Categorization:

Low Risk

Overworked

Flight Risk

Critical


4. Dashboard Insights

Attrition increases sharply after burnout > 60

Sales & Research departments show higher attrition

High-risk employees contribute major revenue loss


5. Results

Identified high-risk employees

Estimated ₹18M+ revenue risk

Provided actionable HR strategies
